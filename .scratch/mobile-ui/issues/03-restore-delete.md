# 确认恢复与删除备份

Status: resolved
Type: task
Blocked by: 02

## 验收

- 恢复最新在打开确认前读取备份历史，按创建时间确定目标。历史恢复使用选中的条目。
- 两个恢复入口都确认游戏、备份、创建时间和整目录替换后果。提交使用确认时的备份 ID。
- 在备份和详情的「更多」分别发起单条或批量删除。各操作只确认一次，显示对象和范围，取消时不发请求。
- 删除成功刷新历史，批量结果采用服务端返回数量。已删除的恢复目标显示明确错误及刷新入口。
- 手机和桌面共用确认与写入状态。用浏览器和临时目录验证取消、多页面变更、请求延迟和连接中断。

规格对应用户故事 19–33、36。
