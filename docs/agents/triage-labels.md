# 分流标签

在工单的 `Status:` 中填写对应角色的状态值。

| 技能角色 | 工单状态 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待提报者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已明确，可交给代理执行 |
| `ready-for-human` | `ready-for-human` | 需要由人处理 |
| `wontfix` | `wontfix` | 已决定关闭该工单 |
